# NASDAQ 100 Time Series Forecasting Pipeline

## 1. Purpose

This project implements a baseline time series forecasting pipeline for the NASDAQ 100 index (`^NDX`). It fetches historical data at various intervals (1h, 15m, 5m, 1m) using `yfinance`, preprocesses the data by calculating technical indicators (log returns, SMAs, RSI), and then uses Facebook's Prophet library to generate forecasts and a simple trading signal.

## 2. Setup

### Prerequisites
- Python 3.x
- `pip` (Python package installer)

### Installation
1.  Clone the repository (or ensure these files are in your project structure).
2.  Navigate to the `src` directory in your terminal.
3.  Install the necessary Python libraries using the provided `requirements.txt` file:
    ```bash
    pip install -r requirements.txt
    ```

## 4. How to Run

The pipeline is typically run in two main stages:

### Stage 1: Fetch Data (All Intervals)
This step downloads the historical data for all configured intervals and saves it into the `data/` directory.
```bash
python src/data_fetcher.py
```
This script only needs to be run once initially, or periodically to update the historical data. If data for a specific interval is missing, `run_forecast.py` will indicate this.

### Stage 2: Run Forecast for a Specific Interval
This script preprocesses the data for the specified interval, trains the Prophet model, generates a forecast, and produces a trading signal.
Replace `{interval}` with one of '1h', '15m', '5m', or '1m'.

```bash
python src/run_forecast.py --interval {interval}
```
**Example for 1-hour interval:**
```bash
python src/run_forecast.py --interval 1h
```
**Example for 15-minute interval:**
```bash
python src/run_forecast.py --interval 15m
```

## 5. Output

When `run_forecast.py` is executed, it will:
1.  Print progress messages to the console.
2.  Save the preprocessed data to a CSV file in the `processed_data/` directory (e.g., `processed_data/preprocessed_ndx_1h.csv`).
3.  Save forecast plots (forecast with actuals, and forecast components) to the `forecast_plots/` directory (e.g., `forecast_plots/prophet_forecast_1h.png`).
4.  Print a summary to the console, including:
    *   The last actual price and its datetime.
    *   The forecasted price for the next period and its datetime.
    *   A generated trading signal ('BUY', 'SELL', or 'HOLD') based on a 0.1% threshold change from the last actual price.

## 6. Limitations

*   **Baseline Model**: The Prophet model used is a baseline with default parameters. For more accurate forecasting, hyperparameter tuning and potentially more complex models or feature engineering would be necessary.
*   **Trading Signal**: The trading signal is very simplistic (based on a fixed percentage change for the next period only) and should not be used for actual trading without significant further development and backtesting.
*   **Data Availability**: `yfinance` data availability and limitations (e.g., range for intraday data) apply. The `data_fetcher.py` script attempts to get a reasonable amount of data within these known limits.
*   **Error Handling**: While some error handling is included, it may not cover all edge cases.
*   **Internet Access**: `data_fetcher.py` requires internet access. `run_forecast.py` assumes data has already been fetched.
*   **Plotly**: The Prophet library can generate interactive plots if `plotly` is installed. This project defaults to static Matplotlib plots, and a message "Importing plotly failed. Interactive plots will not work." might appear if Plotly is not in the environment; this is not critical for the core functionality.
